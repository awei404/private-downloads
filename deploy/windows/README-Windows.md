# BWI Monitor · Windows 安装（三步）

1. 下载 `BWI-Monitor-Windows.zip`，右键 →“全部解压缩”（不要在压缩包里直接双击）。
2. 双击 **Install-BWI-Monitor.bat**，弹出“是否允许”点“是”。没有 Python 会自动安装。
3. 安装过程中会弹出两个粘贴窗口：
   - **飞书 Webhook**：粘贴飞书群机器人地址（https://open.feishu.cn/... 开头）。
   - **TMS 登录 token**：粘贴 Authorization 值（Bearer 开头）。
   跳过也可以：监控台会出现红色按钮，随时可以再粘贴。

装完会自动打开监控台。黑色窗口最后黄色字是**管理员口令（6 位数字）**，每台电脑的浏览器只需输入一次。

**升级**：下载新的 ZIP，同样双击安装即可，直接覆盖旧版本；数据库、token、webhook 和设置都会保留（旧版本自动备份到 `C:\BWI-Monitor\backups`）。

## TMS 登录过期怎么办

监控台顶部会出现红色“TMS 登录失效”，飞书也会收到“⛔ BWI 监控数据中断”。

1. 用浏览器登录 TMS（dms.gofoexpress.com），按 **F12** → **Network（网络）** → 点任意一个 `pageList` 请求。
2. 在 Request Headers 里找到 **Authorization**，复制 `Bearer` 开头的整串。
3. 在监控台点红色按钮 **“更新 TMS 登录”**（或点顶部的 TMS 标签），粘贴 → 确定。

系统会先拿新 token 去 TMS 验证，**有效才保存**，然后立刻重新拉取数据，不需要重启。

## 新功能

同一个 Windows 看板（默认 `http://127.0.0.1:8766/dashboard-v2`）包含原收车、卸货、发车、操作异常预警，以及司机到场、评分、导出和 Check-in 打印。Windows 只启动一个运输监控进程；司机资料在后台只读同步。

- 司机功能仅用于 **BWI.H 始发、首段去 ORF01/RIC01/DCA01/IAD01** 的任务。往返任务按首次离站支线统计，同一 MT 不重复计分。
- 姓名、电话读取 TMS 派车任务登记，不用车辆默认司机代替。实际到场在现场填写，不取 TMS 到车时间。
- 约定到场沿用旧调度已确认的具体 MT 约定。新电脑没有这些约定时显示待确认；如需迁移旧库，请在本地迁移，不经 GitHub。
- 评分沿用迟到、错线路、回货和人工扣分；提供近 30 个营业日均分和人工总分调整。
- Excel 电话默认不导出，可勾选加入。
- 点击任务旁的 **打印 Check-in**，或在任务详情中点击打印。打印页含首站及旧系统地址、完整线路、司机/供应商/车牌、约定和实际到场时间、Dock、回货要求、备注和签字栏。支持 Letter 纸或另存 PDF。
- Dock、回货要求和备注仅用于本次打印。未登记的实际到场保持空缺，不会自动补成当前时间；打印前先保存到场修改。

## 每天使用（不需要命令）

- **上班**点监控台右上角“上班 Start Shift”，**下班**点“下班 End Shift”。上班期间飞书才会发送，不再需要每个班次运行授权命令。
- **飞书正式发送 / 测试模式**：点击顶部的“飞书 …⇄”标签即可切换（需要管理员口令）。同一时间只能有一台电脑正式发送：Windows 切到正式之前，先把 Mac 切到测试模式或停掉。
- **管理员口令**：安装结束时黄色字显示（也在 `.env` 的 `BWI_ADMIN_TOKEN`）。每台电脑的浏览器只需输入一次，之后自动记住；口令改了会自动重新询问。
- **隐藏任务**：收车、发车表格每行右侧有“隐藏”。不需要出现在那里的任务（不经过 BWI、测试任务、已线下处理等）填写原因后隐藏，隐藏后不再显示、不再提醒；表格下方“已隐藏的任务”可以随时恢复。
- **TMS 登录过期或电脑断网**：上班期间飞书会收到“⛔ BWI 监控数据中断”，恢复后收到“✅ 已恢复”。

## 日常

- 程序日志：`data\service.log`；数据库默认 `data\bwi_monitor.db`。
- 修改 `.env` 后，在任务计划程序中重新运行 `BWI TMS Monitor`。
- 原监控规则和通知判定未因司机功能修改。

本包只含程序、测试过的安装脚本和配置模板，不含真实司机资料、凭证或运营数据库。
